# 雾雨启动器 0.2.0 RC 2

本版本打通整合包从下载到安装的整条流程，并改用系统原生窗口管理。

## 本次更新

- 整合包下载结束后自动接续基础游戏安装与整合包导入，整条流程完成时直接打开新实例，不再停在「下载完成」，也不再弹出确认框。
- 下载页的「下载设置」改为直接打开 设置 → 下载，与设置页共用同一份配置。
- 修复恢复下载后的任务跟踪、整合包实例的「下载中」状态，以及本地整合包导入完成后的页面跳转。
- Windows 接入系统原生窗口管理：保留原生窗口样式，最大化/最小化动画、贴靠（Snap）、边缘缩放与双击最大化交给系统，窗口按钮仍绘制在右上角。
- Linux 恢复窗口管理器原生标题栏。
- 修复 macOS 进出全屏后设置分栏拖动条位置漂移；分栏宽度只对显示值做限制，保留用户拖出的宽度。
- 设置右半区顶部新增拖拽条，页面头与侧栏标题也会作为原生标题栏区域用于拖动窗口。
- 导航分栏、页头搜索、设置布局与 macOS 全屏留白改用弹簧动画，窗口跨过断点时不再瞬间跳变。
