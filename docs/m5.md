# M5：加载器安装器

> 状态：完成 · 2026-11-14  
> 范围：Fabric、Quilt、Forge、NeoForge、OptiFine 的版本发现、安装计划、安装执行与启动接线。

## 1. 交付内容

| 加载器 | 版本列表 | 安装方式 | 启动 |
| --- | --- | --- | --- |
| Fabric | `meta.fabricmc.net/v2/versions/loader/<mc>` | 官方 `profile/json` + loader 库 | `inheritsFrom` 子版本 |
| Quilt | `meta.quiltmc.org/v3/versions/loader/<mc>` | 官方 `profile/json` + loader 库 | 同上 |
| Forge 1.13+ | Forge Maven metadata | installer jar + `install_profile.json` + client processors | `BootstrapLauncher` |
| Forge 1.7–1.12 | 同上 | `versionInfo` / `version.json` + 内嵌 universal jar | `LaunchWrapper` |
| NeoForge | NeoForge Maven metadata（1.20.1 走 `net.neoforged:forge`） | 同 Forge 现代流程 | `BootstrapLauncher` |
| OptiFine | BMCLAPI `optifine/versionList` | Patcher 直接补丁原版 jar + launchwrapper | `LaunchWrapper` + `OptiFineTweaker` |

## 2. 分层

```text
fg-loader
  kind.rs       加载器家族、版本 id、Maven 基础地址
  meta.rs       Fabric/Quilt/Forge/NeoForge/OptiFine 版本列表
  planner.rs    LoaderPaths / LoaderRequest / LoaderPlanner
  fabric.rs     Fabric/Quilt profile
  forge.rs      install_profile、data 变量、processors、legacy
  optifine.rs   Patcher / launchwrapper / tweakClass
  execute.rs    zip 解包、Forge processor、OptiFine patcher
  plan.rs       可序列化的 LoaderPlan

fg-game
  install.rs    把 LoaderPlan 合并进 InstallPlan，新增 install.loader 图节点
  instance.rs   [loader] version_id
  launch.rs     子版本客户端 jar 回退到 base_id
```

`LoaderPlan` 在向导阶段生成并写入 `cache/install/<version-id>.json`，执行阶段只读本地文件：

- `versionJson`：Fabric/Quilt 官方 profile，或 Forge/NeoForge installer 内的 `version.json` / `versionInfo`；
- `files`：loader 库、installer、Mojang mappings，统一走 `fg-net` 镜像与校验；
- `steps`：`extract`、`runProcessor`、`patchOptiFine`、`copyFile`。

## 3. Forge / NeoForge 细节

- 只运行 `sides` 为空或包含 `client` 的 processor；server processor 不执行。
- `{SIDE}`、`{MINECRAFT_JAR}`、`{MINECRAFT_VERSION}`、`{ROOT}`、`{INSTALLER}`、`{LIBRARY_DIR}` 在计划阶段展开为绝对路径。
- `{ROOT}` 指向 `<data>/shared`，因此 `{ROOT}/libraries` 与共享库布局一致。
- `data` 中的 `[group:artifact:version]` 映射到 `shared/libraries`；以 `/` 开头的 installer 内文件先解到 `cache/loaders/<kind>/<mc>/data/`。
- `DOWNLOAD_MOJMAPS` 不交给 Java：直接从原版 version json 的 `downloads.client_mappings` 下载到 `{MOJMAPS}`，再交给 `MERGE_MAPPING`。
- processor 主类从 jar 的 `MANIFEST.MF` 读取；执行后校验 `outputs` 声明的 SHA-1。
- installer 内嵌的 `maven/**` 直接解包到共享库，不重复下载。
- 旧版 Forge 的 `install.filePath`（universal jar）解到 `install.path` 对应的库路径；1.7.10 的 `versionInfo` 直接作为子版本。

## 4. OptiFine 细节

- 版本号形如 `HD_U_I6`，拆成 BMCLAPI 下载路径 `optifine/<mc>/HD_U/I6`。
- 现代 installer 含 `optifine/Patcher.class`：执行 `java -cp installer optifine.Patcher <client.jar> <installer> <output.jar>`。
- 旧 installer 不含 Patcher：把 installer 复制为 OptiFine 库。
- launchwrapper 优先使用 installer 内的 `launchwrapper-of-<v>.jar` / `launchwrapper-2.0.jar`，否则下载 `net.minecraft:launchwrapper:1.12`。
- 子版本主类 `net.minecraft.launchwrapper.Launch`，游戏参数追加 `--tweakClass optifine.OptiFineTweaker`。
- 当前只支持独立 OptiFine；与 Forge 同实例共存（放 `mods/`）仍在 `docs/backlog.md`，M8 的内容管理没有覆盖它。

## 5. 接口

| 方法 | 参数 | 结果 |
| --- | --- | --- |
| `loaders.versions` | `{kind, minecraft, limit?}` | `{versions:[{version, stable, label?, note?}]}` |
| `version.plan` | `{version, loaderKind?, loaderVersion?}` | 现有预览字段 + `loaderKind` / `loaderVersion` |
| `install.start` | `{version, instanceId?, instanceName?, loaderKind?, loaderVersion?}` | `{taskId, versionId}` |

`instance.toml` 新增 `[loader] version_id`，保存实际安装的子版本目录名；vanilla 实例留空，回退到 `minecraft`。安装完成标记仍在子版本目录的 `fograin-install.json`。

## 6. 验收

- `cargo test --workspace`。
- `fg-cli loaders <mc> --kind fabric|quilt|forge|neoforge|optifine`。
- `fg-cli install 1.21.4 --loader fabric --loader-version 0.16.9` → 启动命令使用 `fabric-loader-…`。
- `fg-cli install 1.20.1 --loader forge --loader-version 47.4.29` → processor 产出 `forge-1.20.1-47.4.29-client.jar`，hash 校验通过。
- `fg-cli install 1.20.1 --loader optifine --loader-version HD_U_I6` → 产出 `OptiFine-1.20.1_HD_U_I6.jar`。
- 手动真实 installer 测试：`crates/fg-loader/tests/manual_installers.rs`（默认 ignored）。
- Compose：`./apps/compose/gradlew -p apps/compose :shared:desktopTest`。

## 7. 已知限制

- Forge/NeoForge/OptiFine 安装需要 Java；M6 已接入运行时下载，安装入口复用同一套 `fg-java` 选择逻辑，缺 Java 时会先下载官方运行时（见 [m6.md](m6.md)）。
- NeoForge 1.20.1 使用 `net.neoforged:forge` 旧坐标；1.20.2+ 使用 `net.neoforged:neoforge`。
- Forge 1.7–1.12 只支持 installer 自带 `versionInfo` / `version.json` 的版本；更早的畸形 installer 会报 `error.loader.install_profile`。
- OptiFine 安装器由 BMCLAPI 提供（官方站有反爬），`--source official` 仍走 BMCL。
- Fabric API 不是加载器，已从加载器选择中移除；M8 起会作为 Modrinth/CurseForge 的必需前置自动安装（见 [m8.md](m8.md)）。
