# M7：离线账户与第三方服务器登录

> 状态：完成 · 2026-11-15  
> 范围：本地账户仓库、离线账户、Yggdrasil / authlib-injector 第三方登录、账户页、
> 启动时账户选择与令牌续期。  
> 明确不做：皮肤/披风的查询、上传、本地皮肤与皮肤管理页；微软正版登录（M11）。

## 1. 范围调整

M7 原计划包含「Yggdrasil / authlib-injector、账户页、皮肤」。本次按以下边界收敛：

| 能力 | M7 | 说明 |
| --- | --- | --- |
| 离线登录 | ✅ | 名称 → UUID v3，沿用 M3 的 `OfflinePlayer:<name>` 规则 |
| 第三方服务器登录 | ✅ | Yggdrasil API + authlib-injector；支持 LittleSkin 等 ALI 服务 |
| 账户页与切换 | ✅ | 主页头像打开账户面板；选择、添加、删除、重新登录 |
| 皮肤管理 | ❌ 移出计划 | 不做查询/上传/本地皮肤/披风/皮肤预览；账户头像只用名称首字母 |
| 正版登录 | ⏸ 搁置 | 保留 `AccountKind::Microsoft` 数据位，入口显示「后续版本」，仍归 M11 |

皮肤不是登录的前置条件：authlib-injector 会在游戏内用第三方服务端的角色属性渲染皮肤，
启动器不下载、不缓存、不上传皮肤资源。因此移除皮肤管理不影响第三方服务器登录。

## 2. 交付内容

| 能力 | 实现 |
| --- | --- |
| 账户仓库 | `<root>/accounts.json` 元数据 + `<root>/credentials.json` 令牌（Unix 0600） |
| 离线账户 | 名称校验、UUID v3、默认账户迁移自 `[game] username` |
| 第三方登录 | ALI 发现（`x-authlib-injector-api-location`）、`authenticate`、`refresh`、`validate`、`invalidate` |
| 角色选择 | `availableProfiles` 多角色时由用户选择，再以 `selectedProfile` 刷新绑定 |
| 令牌续期 | 启动前 `validate`，失效时自动 `refresh`；仍失败则要求重新登录 |
| authlib-injector | 官方 `latest.json` → 镜像 → SHA-256 校验 → `cache/authlib-injector/` |
| 启动接线 | `-javaagent:<jar>=<apiRoot>`、`-Dauthlibinjector.side=client`、`--userType mojang`、`--userProperties` |
| 账户页 | 主页头像 → 账户面板：列表、离线表单、第三方表单（含 LittleSkin 预设）、角色选择、删除、切换 |
| CLI | `fg-cli account list/add-offline/login/select/remove/refresh/discover/injector` |

## 3. 分层

```text
fg-auth
  account.rs      Account / AccountStore / accounts.json / credentials.json
  offline.rs      既有 OfflineAccount（名称、UUID v3、用户名校验）
  yggdrasil.rs    YggdrasilClient：发现、登录、刷新、验证、吊销
  injector.rs     authlib-injector latest.json、镜像下载、缓存与校验
  session.rs      AuthSession：启动器与 fg-game 之间的账户边界

fg-game
  launch.rs       LaunchPlan::build 接收 AuthSession，而不是 OfflineAccount

fg-ffi
  accounts.list / addOffline / select / remove / refresh
  accounts.yggdrasil.discover / login / selectProfile
  launch.start    读取选中的账户；第三方账户先续期并准备 injector

fg-cli
  account ...；launch --account <id>（--username 仅作一次性离线覆盖）

apps/compose
  app/AccountActions.kt + AccountUiState
  ui/accounts/AccountSheet.kt；主页头像与启动按钮读取同一选中账户
```

`fg-auth` 依赖 `fg-core`、`fg-net`（HTTP 客户端、镜像表、下载引擎），不接触实例或启动器
UI；`fg-game` 只认 `AuthSession`，不知道账户来自离线还是 Yggdrasil。

## 4. 存储

`accounts.json` 只保存元数据，令牌单独放在 `credentials.json`：

```json
{
  "schemaVersion": 1,
  "selectedId": "b50ad385-829d-3141-a216-7e7d7539ba7f",
  "accounts": [
    {
      "id": "b50ad385-829d-3141-a216-7e7d7539ba7f",
      "kind": "offline",
      "name": "Steve",
      "uuid": "b50ad385-829d-3141-a216-7e7d7539ba7f",
      "server": null,
      "serverName": null,
      "userId": null,
      "properties": "{}",
      "createdAtMs": 1794712058419
    },
    {
      "id": "8f0c…",
      "kind": "yggdrasil",
      "name": "Fograin",
      "uuid": "8f0c…",
      "server": "https://littleskin.cn/api/yggdrasil",
      "serverName": "LittleSkin",
      "userId": "…",
      "properties": "{\"textures\":[…]}" ,
      "createdAtMs": 1794712058419
    }
  ]
}
```

```json
{
  "schemaVersion": 1,
  "tokens": {
    "8f0c…": {
      "accessToken": "…",
      "clientToken": "…"
    }
  }
}
```

- `id` 与角色 UUID 一致，重新登录同一角色会原地更新，不会产生重复账户。
- 离线账户的 `id` 由名称派生，因此同名离线账户天然幂等。
- 令牌文件在 Unix 上以 `0600` 写入；Windows 依赖用户目录 ACL。密码从不落盘。
- 旧配置只有 `[game] username` 时，首次启动迁移为一个选中的离线账户；不删除旧字段，
  以便降级。
- 系统凭据库（macOS Keychain / Windows Credential Manager / Linux Secret Service /
  Android Keystore）作为后续硬化项列入 `docs/backlog.md`，不作为 M7 的验收条件。

## 5. 登录流程

### 5.1 离线

1. 校验 3–16 位 `[A-Za-z0-9_]`；
2. `uuid = UUID v3("OfflinePlayer:" + name)`，与在线模式关闭的服务端一致；
3. 写入 `accounts.json` 并设为选中；
4. 启动参数使用 `--userType legacy`、`accessToken = 0`、`auth_session = token:0:<uuidHex>`。

### 5.2 第三方（Yggdrasil / authlib-injector）

1. 规范化 API Root：补 `https://`、去掉尾部 `/`，接受用户误贴的 `/authserver` 后缀；
2. GET API Root，优先采用 `x-authlib-injector-api-location` 返回的地址；解析 `meta.serverName`；
3. 生成随机 `clientToken`，POST `/authserver/authenticate`，`requestUser = true`；
4. 若响应带 `selectedProfile`，直接保存账户；
5. 若没有且 `availableProfiles` 非空，返回角色列表供 UI 选择；选择后
   POST `/authserver/refresh` 并带 `selectedProfile`，把令牌绑定到该角色；
6. 保存 `accessToken` / `clientToken` / 角色 / `user.id` / `user.properties`。

### 5.3 启动前

1. 读取选中账户（或 `launch.start` 的 `accountId` 覆盖）；
2. 第三方账户：`validate` 令牌；403 时自动 `refresh`；刷新仍失败返回
   `error.auth.expired`，账户页可重新登录；
3. 确保 authlib-injector 已缓存；首次启动下载并校验，之后直接用缓存；
4. 组装 `AuthSession`：
   - `--username` / `--uuid` / `--accessToken`
   - `--userType mojang`（第三方）、`legacy`（离线）
   - `--userProperties` 为服务端返回的角色属性 JSON；
   - `-javaagent:<cache>/authlib-injector-<version>.jar=<apiRoot>` 与
     `-Dauthlibinjector.side=client`。

authlib-injector 的官方启动器规范要求第三方 Yggdrasil 使用 `user_type = mojang`；
皮肤、披风由注入器在游戏内从服务端属性读取，启动器不参与。

## 6. 接口

| 方法 | 参数 | 结果 |
| --- | --- | --- |
| `accounts.list` | `{}` | `{accounts:[AccountRow], selectedId}` |
| `accounts.addOffline` | `{name}` | `{account, selectedId}` |
| `accounts.select` | `{id}` | `{selectedId}` |
| `accounts.remove` | `{id}` | `{ok, selectedId}`；第三方账户先尽力 `invalidate` |
| `accounts.refresh` | `{id?}` | `{account, selectedId}`；默认刷新选中账户 |
| `accounts.yggdrasil.discover` | `{server}` | `{server, serverName, implementationName?, implementationVersion?}` |
| `accounts.yggdrasil.login` | `{server, username, password}` | `{account, selectedId}` 或 `{selectionRequired:true, pendingId, server, serverName, profiles:[{id,name}]}` |
| `accounts.yggdrasil.selectProfile` | `{pendingId, profileId}` | `{account, selectedId}` |
| `launch.start` | `{instanceId, accountId?}` | `{pid}`；旧 `username` 参数保留为一次性离线覆盖 |

`AccountRow`：`id`、`kind`（`offline` / `yggdrasil`）、`name`、`uuid`、`server`、
`serverName`、`selected`。响应中不含 access token、client token 或密码。

令牌选择是进程内状态：登录返回的 `pendingId` 只在内存中保存 10 分钟，超时或重启后
重新登录，不保存密码。

## 7. 错误键

| messageKey | 场景 |
| --- | --- |
| `error.auth.server_url` | API Root 不是合法的 http(s) 地址 |
| `error.auth.server_unreachable` | 发现/登录请求无法连接 |
| `error.auth.server_metadata` | API Root 响应不是合法 JSON |
| `error.auth.server_status` | 发现/登录返回非 2xx（非凭证错误） |
| `error.auth.credentials_required` | 用户名、密码或 clientToken 为空 |
| `error.auth.invalid_credentials` | 用户名或密码错误（403 ForbiddenOperation） |
| `error.auth.forbidden` | 其他 403 |
| `error.auth.response` | 登录响应缺字段或格式错误 |
| `error.auth.no_profiles` | 账户没有可用角色 |
| `error.auth.profile_not_found` / `error.auth.profile_required` / `error.auth.selection_expired` | 角色选择参数失效 |
| `error.auth.login_required` / `error.auth.expired` | 缺少令牌 / 令牌失效 |
| `error.auth.account_not_found` / `error.auth.no_account` | 账户 id 不存在 / 没有选中账户 |
| `error.auth.kind_mismatch` / `error.auth.injector_required` | 账户类型或注入器状态不支持启动 |
| `error.auth.injector_metadata` / `error.auth.injector_download` | injector 元数据或下载失败 |
| `error.auth.microsoft_pending` | 正版登录入口（M11） |
| `error.auth.conflicting_account` | CLI 同时给了 `--account` 与 `--username` |
| `error.auth.accounts_parse/read/write/serialize/schema` | 账户仓库读写或版本不支持 |

## 9. 已知限制

- 不含皮肤管理：没有皮肤上传/下载、披风、本地皮肤文件、皮肤预览和头像渲染；
  这些需求不再属于 M7。
- 不含微软正版登录：`AccountKind::Microsoft` 仅占位，UI 显示「后续版本」。
- 令牌存于 `credentials.json`（Unix 0600），尚未接入系统凭据库；见 backlog。
- 不保存密码，因此 `signout` 不可用；删除第三方账户时调用 `invalidate` 吊销令牌。
- authlib-injector 使用官方 `latest.json` 与缓存；缓存优先，不会自动检查新版本。
  需要更新时删除 `<root>/cache/authlib-injector/` 后重新启动或运行 `account injector`。
- 不提供手动替换 jar 的入口。
- 第三方登录依赖服务端实现 Yggdrasil 扩展 API；仅实现旧版 Yggdrasil 的服务端可能缺少
  `meta.serverName`，此时显示主机名，但仍可登录。
- 皮肤域名白名单（`skinDomains`）由 authlib-injector 在游戏内校验，启动器不解析。
- Android 的第三方登录与桌面共用同一核心；账户令牌文件位于应用私有目录。
