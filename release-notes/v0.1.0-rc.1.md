# 雾雨启动器 0.1.0 RC 1

0.1.0 的首个预览版，用于正式发布前的体验与问题反馈。

## 本次更新

- 支持正式版、快照与远古版本安装，以及 Fabric、Quilt、Forge、NeoForge、OptiFine 加载器。
- 自动发现系统 Java，缺失时可按 Mojang 官方目录下载运行时。
- 实例使用独立游戏目录，可配置内存、JVM 参数、分辨率与全屏，支持导入外部 `.minecraft`。
- 支持离线账户与 Yggdrasil / authlib-injector 多角色登录。
- 支持 Modrinth 与 CurseForge（经 MCIM）内容浏览、安装与更新，以及整合包导入导出。
- 支持日志、崩溃报告与 `hs_err` 分析，导出脱敏诊断包；管理世界与备份。
- Windows / Linux 改为无边框窗口：自绘标题栏、窗口按钮与拖拽/缩放，移除 AWT 菜单栏。
- 修复 Windows 启动和进入下载页时黑色控制台窗口闪烁；启动阶段的平台与主题探测不再同步等待子进程。
- 支持简体中文、繁體中文、English、日本語。

## 预览版说明

- 这是预发布版本，桌面安装包内部版本仍为 `1.1.0`，与正式版相同；在预览版和正式版之间切换前请先卸载旧版本。
- Android 预览包与正式版的 versionCode 同为 `100`，安装正式版前请先卸载。
- 预发布版本不会被 GitHub 的 `/releases/latest` 视为最新正式版，因此不会收到其他预览版的更新提示；`0.1.0` 正式版发布后会正常提示。
- macOS 预览包为 Apple 芯片（arm64）版本。
- 未配置签名时安装包未签名：macOS 首次打开需要在「系统设置 → 隐私与安全性」中允许，Windows SmartScreen 需要选择「仍要运行」，Android 未签名 APK 无法安装。
- 暂不提供微软正版登录、皮肤与披风管理。
