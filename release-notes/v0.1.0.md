# 雾雨启动器 0.1.0

首个公开版本。

雾雨启动器是面向 Minecraft Java 版的跨平台启动器：Rust 核心负责下载、安装、账户与启动，Compose Multiplatform 在 Android 与桌面端提供同一套界面。

## 本次亮点

- 安装正式版、快照与远古版本，支持 Fabric、Quilt、Forge、NeoForge 与 OptiFine。
- 自动发现系统 Java；缺少运行时可按 Mojang 官方目录下载。
- 实例使用独立游戏目录，可覆盖内存、JVM 参数、分辨率与全屏设置，也可导入外部 `.minecraft`。
- 离线账户与 Yggdrasil / authlib-injector 多角色登录。
- 从 Modrinth 与 CurseForge（经 MCIM）浏览、安装和更新模组、资源包、光影与数据包。
- 导入/导出 `.mrpack`、CurseForge、HMCL、MultiMC 整合包，并管理世界与备份。
- 分析 `latest.log`、崩溃报告与 `hs_err`，导出脱敏诊断包。
- 启动时自动检查 GitHub Release，右下角提示新版本，点击即可打开对应的发布页。
- 简体中文、繁體中文、English、日本語界面。

## 下载

| 平台 | 安装包 | 说明 |
| --- | --- | --- |
| Windows | `.msi` | Windows 10 及以上 |
| macOS | `.dmg` | Apple 芯片（arm64） |
| Linux | `.deb` | 需要 GTK 3 与 OpenGL |
| Android | `.apk` | Android 8.0（API 26）及以上，arm64 / x86_64 |

所有产物的 SHA-256 校验值见 `SHA256SUMS.txt`。

## 安装提示

- macOS 如果提示无法验证开发者，请在「系统设置 → 隐私与安全性」中允许打开。
- Windows 如果出现 SmartScreen 提示，请选择「仍要运行」。
- 更新提示只负责跳转到本发布页；下载和安装仍需手动完成。

## 已知限制

- 暂不支持微软正版登录（需要 Azure 应用审核）。
- 不提供皮肤与披风管理；第三方皮肤由服务端与 authlib-injector 在游戏内处理。
- 不提供 iOS 与 Web 版本；macOS 目前只发布 Apple 芯片构建。

## 反馈

问题与建议请提交到 [Issues](https://github.com/crystelf/fograin-launcher/issues)，附上启动器日志或诊断包会更快定位。

启动器的实现思路参考了 PCL / PCL.Core（Apache-2.0）与 HMCL / HMCLCore（GPL-3.0），本项目为独立实现，并保留上述项目的开源许可。
