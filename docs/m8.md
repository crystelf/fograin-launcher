# M8：内容管理、世界与内容下载页

> 状态：完成 · 2026-11-15  
> 范围：实例内的模组、资源包、光影与世界管理；Modrinth / CurseForge（MCIM）内容浏览、
> 版本选择、必需前置解析与安装；内容更新检查；世界备份与恢复；CLI、FFI 与 Compose UI 接线。  
> 明确不做：**原理图（`.litematic` / `.schem` / `.nbt`）已从 M8 与全部后续计划中删除**；
> 整合包（M9）、数据包（M9）、CurseForge 指纹更新、内容图标与封面渲染、拖入本地文件导入。

## 1. 范围与计划调整

M8 原计划是「模组、资源包、光影、世界、原理图、下载页六类资源」。本次调整如下：

| 能力 | M8 | 说明 |
| --- | --- | --- |
| 模组管理 | ✅ | 扫描、元数据、启用/禁用、删除、更新检查、在线安装与必需前置 |
| 资源包管理 | ✅ | `pack.mcmeta`、启用/禁用、删除、更新检查、在线安装 |
| 光影管理 | ✅ | `shaderpacks/`、启用/禁用、删除、更新检查、在线安装 |
| 世界管理 | ✅ | 列表、备份、恢复为新世界、删除世界与备份 |
| 内容下载页 | ✅ | 模组 / 资源包 / 光影三个分类，Modrinth 与 CurseForge 切换，目标实例过滤 |
| 原理图 | ❌ 从计划删除 | 不再扫描、下载、备份或展示 `.litematic` / `.schem` / `.nbt`；实例目录不再创建 `schematics/` |
| 数据包 | ⏸ M9 | 数据包按世界而不是按实例生效，和世界导入/导出一起做更合适 |
| 整合包 | ⏸ M9 | `.mrpack` / CurseForge 整合包导入保持 M9 |
| 内容图标/封面 | ❌ 本里程碑不做 | 当前使用字母色块；本地图标缓存与网络图片加载列入 backlog |
| CurseForge 指纹 | ❌ 本里程碑不做 | 未索引的 CurseForge 文件无法可靠识别，更新检查按「未知来源」计数 |
| 本地文件导入 | ❌ 本里程碑不做 | 没有新增文件选择器；用户仍可手动放入实例目录后刷新 |

原理图被删除的理由：

1. 启动器的 M8 核心价值是“让实例可玩”——模组、资源包、光影和世界直接影响启动与存档；原理图是
   建筑辅助工具的数据文件，不参与启动。
2. 原理图没有统一的安装目录、加载器或版本约束，`.litematic` / `.schem` / `.nbt` 的预览需要
   额外的 NBT 解析与渲染，收益与成本不匹配。
3. 删除后，`fg-content`、`fg-world`、实例目录布局、FFI、CLI 与 UI 都不再保留原理图分支，
   后续里程碑无需再为它做迁移或兼容。

## 2. 交付内容

| 能力 | 实现 |
| --- | --- |
| 本地扫描 | `mods/*.jar`、`resourcepacks/*.zip|目录`、`shaderpacks/*.zip|目录`；跳过隐藏文件 |
| 元数据 | Fabric `fabric.mod.json`、Quilt `quilt.mod.json`、Forge/NeoForge `META-INF/mods.toml` / `neoforge.mods.toml`、旧 `mcmod.info`；资源包 `pack.mcmeta` |
| 启用/禁用 | `.disabled` 后缀重命名，与 HMCL/PCL/Prism 兼容 |
| 删除 | 文件或目录删除；同步清理实例内容索引 |
| 内容索引 | `instances/<id>/content.json` 记录来源、项目、版本与 SHA-1 |
| 在线搜索 | Modrinth `/v2/search`；CurseForge `/v1/mods/search`（只走 MCIM） |
| 版本列表 | Modrinth `/v2/project/{id}/version`；CurseForge `/v1/mods/{id}/files` |
| 必需前置 | Modrinth `dependencies[dependency_type=required]`；CurseForge `relationType=3`，最多 4 层 |
| 下载 | 每个文件一个任务节点；SHA-1/SHA-512/大小校验，镜像候选、断点续传与内容缓存复用 `fg-net` |
| 更新检查 | 已索引文件按项目查询最新兼容版本；未索引 Modrinth 文件按 SHA-1 批量查询；CurseForge 未索引文件计为未知 |
| 世界 | `saves/` 列表（大小、修改时间、图标标记）、zip 备份、恢复为新世界、删除世界/备份 |
| 实例详情页 | 实例库点击实例进入；精简操作栏 + 模组 / 资源包 / 光影 / 世界四个分页，下载页式布局 |
| 下载页 | 三个内容分类；来源切换、目标实例、搜索、项目详情、版本选择与安装 |
| CLI | `fg-cli content ...` 与 `fg-cli world ...` |
| FFI | `content.*` 与 `worlds.*`，全部 camelCase；长任务走 `task.*` 事件 |

## 4. 本地内容与索引

### 4.1 扫描

- 目录：`<game dir>/mods`、`resourcepacks`、`shaderpacks`。
- 文件：模组 `.jar`；资源包与光影 `.zip` 或目录。
- `.disabled` 后缀表示禁用；显示名去掉后缀，`enabled` 取反。
- 元数据只读归档条目，单条上限 2 MiB，避免恶意 zip。
- 模组标题顺序：元数据 `name`/`displayName` → 文件名主干。
- 版本：Fabric/Quilt 的 `version`；Forge 的 `version`（`${file.jarVersion}` 占位符视为未知）。
- 资源包：`pack.mcmeta` 的 `pack_format`；`description` 支持字符串或 JSON 文本组件。
- 光影：识别 `shaders/` 条目，标题使用文件名；不做着色器解析。

### 4.2 索引

`instances/<id>/content.json`：

```json
{
  "schemaVersion": 1,
  "items": [
    {
      "fileName": "sodium-fabric-0.6.13+mc1.21.4.jar",
      "kind": "mod",
      "source": "modrinth",
      "projectId": "AANobbMI",
      "projectName": "Sodium",
      "versionId": "c3YkZvne",
      "versionNumber": "mc1.21.4-0.6.13-fabric",
      "sha1": "…",
      "installedAtMs": 1794712058419
    }
  ]
}
```

索引是可选的：文件消失后扫描不再列出；手动放入的文件没有索引，仍会出现在实例详情页，
只是更新检查只能依赖 Modrinth SHA-1 或显示为未知来源。写入使用 `*.tmp` + rename。

启用/禁用与删除会同步更新索引中的 `fileName`，避免更新检查指回旧文件。

## 5. 在线内容

### 5.1 来源与镜像

- Modrinth：`https://api.modrinth.com/v2`，镜像规则走 `fg-net`（MCIM）。
- CurseForge：`https://api.curseforge.com/v1`，`mirrors.toml` 将其标记为
  `official = false`，只经 MCIM 访问；启动器不携带 CurseForge API key。
- 请求先尝试首选镜像，失败后按规则回退；API JSON 使用条件缓存。
- 项目 id 会校验，禁止路径分隔符与 `..`。

### 5.2 搜索与版本

- Modrinth facets：`project_type`、`versions:<mc>`、`categories:<loader>`；Quilt 同时匹配
  `quilt` 与 `fabric`。
- CurseForge：`gameId=432`、`classId`（6 模组 / 12 资源包 / 6552 光影）、
  `gameVersion`、`modLoaderType`（1 Forge / 4 Fabric / 5 Quilt / 6 NeoForge）。
- 版本列表在本地按 `published` 降序排序，不依赖镜像返回顺序。
- 无适配版本时返回 `error.content.version_missing`，UI 显示“没有适配当前实例的版本”。

### 5.3 安装计划

1. 解析根项目与指定版本（缺省取最新兼容版本）。
2. 收集必需前置，递归到最多 4 层；已在实例索引中的项目跳过。
3. 每个前置查询项目标题；单个前置失败只产生 warning，不影响主文件。
4. 清理文件名（禁止 `/`、`\`、`..`），同批重名加项目 id 与序号。
5. 生成 `ContentPlan`：文件、大小、SHA-1/SHA-512、目标目录、替换文件。
6. 每个文件一个 `TaskGraph` 节点；末尾 `content.index` 节点依赖全部文件节点，只有全部成功
   才写入索引并删除 `replaceFiles` 旧文件。任务名为 `content:<项目名>`，进度走
   `task.progress` / `task.finished`。

模组安装要求实例有 Fabric / Quilt / Forge / NeoForge 加载器；原版实例返回
`error.content.loader_required`，UI 在下载页与项目详情里提前提示。资源包与光影对原版实例可用。

### 5.4 更新检查

- 已索引文件：按项目查询最新兼容版本，`versionId` 不同即可更新。
- 未索引文件：计算 SHA-1，最多 50 个一批调用 Modrinth `/v2/version_files/update`；
  返回版本的主文件 SHA-1 与本地相同则视为已是最新。
- CurseForge 未索引文件无法识别，计入 `unknown`，不会产生假更新。
- 更新安装复用 `content.install`，`replaceFiles` 指向旧文件名；只有新文件全部下载成功后才
  删除旧文件并替换索引。

## 6. 世界与备份

- 列表：`saves/` 下的一级目录，忽略符号链接与隐藏目录；返回大小、修改时间、是否有
  `icon.png`。不解析 `level.dat`（属于 M9）。
- 备份：`<root>/backups/<instance-id>/<YYYYMMDD-HHmmss>.zip`；跳过 `session.lock`；
  符号链接不打包。
- 恢复：解压到新的 `saves/<name>`；拒绝同名世界；条目必须通过 `enclosed_name` 检查，
  总解压体积上限 16 GiB、条目数上限 20 万；失败时清理临时目录。
- 删除：世界目录与备份文件都要求单级名称，拒绝 `..` 与路径分隔符。

## 7. 接口

| 方法 | 参数 | 结果 |
| --- | --- | --- |
| `content.local` | `{instanceId}` | `{items:[LocalContent], counts:{mod,resourcepack,shaderpack,enabled}, indexPath}` |
| `content.toggle` | `{instanceId, kind, fileName, enabled}` | `{ok, fileName}`；返回重命名后的文件 |
| `content.delete` | `{instanceId, kind, fileName}` | `{ok}`；同时清理索引 |
| `content.search` | `{source?, kind, query, instanceId?, gameVersion?, loader?, offset?, limit?}` | `CoreContentSearchPage` |
| `content.versions` | `{source?, projectId, kind, instanceId?, gameVersion?, loader?}` | `{source, project, versions}` |
| `content.plan` | `{source?, projectId, versionId?, instanceId, kind, world?}` | `{source, projectName, versionId, files, totalBytes, items, warnings}`；只解析依赖，不排队任务 |
| `content.install` | `{source?, projectId, versionId?, instanceId, kind, world?, replaceFiles?, installDependencies?}` | `{taskId, projectName, versionId, files, totalBytes, items, warnings}`；`installDependencies=false` 时只装本体 |
| `content.updates` | `{instanceId, kind?}` | `{checked, updates, unknown, warnings}` |
| `worlds.list` | `{instanceId}` | `{worlds, backups}` |
| `worlds.backups` | `{instanceId}` | `{backups}` |
| `worlds.backup` | `{instanceId, name}` | `{ok, backup, backups}` |
| `worlds.restore` | `{instanceId, backup, name}` | `{ok, path, worlds, backups}` |
| `worlds.delete` | `{instanceId, name}` | `{ok, worlds}` |
| `worlds.backup.delete` | `{instanceId, backup}` | `{ok, backups}` |

`LocalContent`：`kind`、`fileName`、`displayName`、`enabled`、`path`、`sizeBytes`、
`modifiedMs`、`title`、`version`、`loader`、`description`、`packFormat`、`source`、
`projectId`、`projectName`、`versionId`。

`ContentVersion` 的 `file` 只暴露文件名、URL、大小与哈希；项目依赖以
`{projectId, versionId, kind, name}` 表示。

## 8. 错误键

| messageKey | 场景 |
| --- | --- |
| `error.content.kind` / `error.content.source` | 不支持的内容类型或来源 |
| `error.content.request` / `error.content.response` | API 不可达或响应格式错误 |
| `error.content.version_missing` | 没有适配当前实例的版本 |
| `error.content.version_mismatch` / `error.content.version_incompatible` | 版本不属于该项目，或与游戏版本/加载器不兼容 |
| `error.content.no_files` / `error.content.download_disabled` | 版本没有文件，或作者禁止第三方下载 |
| `error.content.loader_required` | 原版实例尝试安装模组 |
| `error.content.file` / `_missing` / `_conflict` | 文件名不安全、文件不存在或重命名冲突 |
| `error.content.delete` | 删除内容失败 |
| `error.content.index_read/parse/write/serialize/schema` | 内容索引读写失败 |
| `error.content.update` | 更新检查失败 |
| `error.world.name` / `error.world.not_a_world` | 世界名称或目录不安全 |
| `error.world.missing` / `error.world.exists` | 世界不存在 / 恢复目标已存在 |
| `error.world.backup_*` | 备份不可读、写入失败、名称非法、条目不安全或体积超限 |
| `error.world.delete` / `error.world.restore` | 删除或恢复失败 |

## 9. UI

### 9.1 下载页

- 「游戏」以外的三个 M8 分类进入内容浏览器；「整合包」「数据包」保留后续提示。
- 页头：目标实例下拉位于搜索框左侧、与搜索框同一行，切换实例后按新实例的 Minecraft 版本与加载器重新搜索。
- 整合包页头：不再显示「新实例」标签（项目 sheet 已说明安装到新实例），位置改为加载器筛选
  「全部加载器 / Forge / NeoForge / Fabric / Quilt」；筛选变化立即重新搜索。
- 内容区顶部：来源切换（Modrinth / CurseForge）；结果行右侧显示当前实例的 Minecraft 版本与加载器。
- 搜索框与页头共用；输入后 350 ms 防抖查询。
- 宽窗口两列项目卡片，窄窗口单列；卡片显示标题、来源、下载量、分类与两行简介。
- 项目详情 sheet：目标实例、「版本」下拉（正式版 / 测试版 / 内测版 / 全部版本，默认正式版）、
  版本列表、文件大小、必需前置数量、安装按钮；每个版本行用彩色圆点区分正式版/测试版/内测版，
  当前筛选没有版本时提供「查看全部版本」。原版实例安装模组时禁用按钮并提示需要加载器。
- 有必需前置的模组在点安装时先调用 `content.plan` 解析缺失前置：弹出的「缺少前置」对话框列出
  未安装的适配前置，可选择「自动下载并安装」或「仅安装本体」；已安装的前置不会重复下载。
- 安装后关闭详情并显示提示；进度进入任务队列。

### 9.2 实例详情页与内容管理

- 入口：实例库点击任意实例进入详情页；不再弹出预览 sheet，也不再使用行尾的「更多」菜单。
- 布局：与下载页一致，页头 + 单行操作栏 + 分类栏 + 工具栏 + 内容列表；操作栏只有版本信息
  与开始/设置/收藏，不再有概览卡片、占用空间/内容数/上次游玩指标或「已就绪」标签。
- 分页：模组 / 资源包 / 光影 / 世界，标签带数量；分类栏与下载页共用 `SegmentedTabRail`。
- 搜索：页头搜索框按标题、文件名、版本、简介过滤当前分页；世界分页同时过滤世界与备份。
- 模组/资源包/光影行：标题、版本/加载器/格式/大小、简介、启用开关、删除、可更新标记与更新按钮。
- 世界行：大小、修改时间、备份、删除；备份区支持恢复为新世界与删除备份。
- 「检查更新」一次检查全部内容；结果显示在行内，未知来源数量显示在工具栏。
- 删除与恢复都有确认对话框；恢复默认名称为备份文件名 + `-restored`。
- 设置页的「模组管理 / 资源包管理 / 光影包管理 / 世界管理」跳回详情页对应分页。
- 空分页提供「获取内容」：直接打开下载页对应分类，并把目标实例预设为当前实例。

### 9.3 入口、返回与动效

- 实例库是一个 `AnimatedContent` 阶段栈：列表 → 详情 → 设置；返回依次回退。
- 页面切换统一走 `fograinPageTransition`（与下载页列表 → 安装页 → 加载器版本页相同）；
  分页切换统一走 `fograinTabTransition`（与下载页分类切换相同）。
- 项目详情仍是下载页上的 sheet；实例详情、实例设置与内容管理不再是 sheet。
- `Esc`/系统返回先关项目详情，再回退实例设置/详情；`canGoBack` 与 `back()` 同步更新。

## 11. 已知限制

- **不做原理图**：没有扫描、预览、下载、备份或 UI 入口；实例目录也不再创建 `schematics/`。
- 数据包未接入：它按世界生效，等 M9 做世界导入/导出时一起处理。
- 整合包仍为 M9；实例详情页不提供“更新整合包”。
- CurseForge 未索引文件不做指纹识别，更新检查计为未知；Modrinth 也只有 SHA-1 更新检查，
  不检查项目主页的版本变更说明。
- 内容图标/封面没有加载：网络图片需要跨平台图片加载器；本地 jar 图标缓存也留到后续。
- 不支持从文件选择器导入 `.jar`/`.zip`；文件拖放与本地安装列入 backlog。
- 世界不解析 `level.dat`，显示的是文件夹名；没有游戏模式、种子、最后游玩时间。
- 世界备份只在启动器内恢复为新世界，不提供覆盖恢复；恢复大世界可能耗时，UI 没有取消按钮。
- 内容更新检查是串行请求；项目多时需要数秒，未做并发与 6 小时缓存。
- 不做依赖冲突检测或版本约束求解：每个必需前置取最新兼容版本，可能不是最优组合。
