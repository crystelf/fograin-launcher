# 雾雨启动器 0.2.0 RC 3

本版本加入 Crystelf Lab 社区，可在启动器内浏览信息流、发帖并查看资料。

## 本次更新

- 新增「社区」页，提供本地、全局与关注三条信息流；未登录可以浏览本地与全局内容，在浏览器用 Crystelf Lab 账号授权一次即可登录，账户面板可重新登录或退出。
- 支持回复、转发与引用转发、表情回应、参与投票和关注用户。
- 发帖支持图片与视频附件、内容警告、可见性、话题标签、@提及、发起投票和定时发布，发布前可预览。
- 个人资料页展示关注关系、帖子与简介，支持下拉展开封面、滚动收起。
- 社区视频支持进度拖动、音量调节、全屏与手势操作；图片查看器可前后切换并保存到本地。
- 设置 → 通用新增「默认显示账号」，主页头像与昵称可优先显示社区账号或启动器账号。
- 调整导航：导航栏新增「社区」，设置改为从主页右上角齿轮或桌面导航栏底部进入。
- 信息流占满窗口宽度，正文保持居中的阅读宽度，滚轮在两侧留白处也能滚动。

## 注意

- Linux 播放社区视频需要系统安装 GStreamer（含 base 与 good 插件）；若视频无法播放，请先安装。
